# ⚔️ DUNGEON ZERO

### A dark fantasy dungeon-crawler RPG built with Python and Pygame.

> A kingdom swallowed by darkness. Dungeons filled with forgotten secrets. One hero willing to descend into the unknown.

---

## 🎮 About

**Dungeon Zero** is a 2D action RPG featuring procedurally generated dungeons, real-time combat, character progression, enemies, loot, and boss encounters.

Explore the remains of a cursed kingdom, fight increasingly dangerous creatures, discover powerful equipment, and venture deeper into the darkness.

## ✨ Planned Features

- 🗡️ Real-time combat
- 🏰 Procedurally generated dungeons
- 👹 Multiple enemy types
- 🎒 Inventory and equipment system
- 📈 XP and character progression
- 💎 Randomized loot and treasures
- 👑 Floor bosses
- 💾 Checkpoint-based saving
- 🌑 Dark fantasy pixel-art atmosphere

## 🛠️ Built With

- Python
- Pygame
- JSON
- Git & GitHub
